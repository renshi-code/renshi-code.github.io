## SimCore/RISC-V (SimRV)

[SimRV](https://github.com/archlab-sciencetokyo/SimRV) is an open-source RISC-V CPU simulator developed at the Architecture Laboratory (ArchLab) at the Institute of Science Tokyo. The project has been active since 2018.

### Overview

SimRV simulates the behaviour of a RISC-V core, providing a platform for architecture research and education. It is written in C++ and designed for simplicity and extensibility.

### Key Features

- Full RISC-V core simulation
- Written in C++ for performance
- Open-source and actively maintained
- Used for computer architecture research at ArchLab
